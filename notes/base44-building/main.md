# Building with Base44

## Overview

Abdulwaris received Base44 onboarding guidance after signing in with Google on August 27, 2026. The recommended workflow is to plan the idea first, provide specific requirements, use a template when useful, refine the design in Edit mode, then publish and explore the app dashboard.

## Workflow

1. **Plan first.** Use Plan mode to map out the idea before building.
2. **Be specific.** Detailed requirements and a reference example can improve the result; an existing project can also be migrated into Base44.
3. **Start from a template when useful.** A template can provide a foundation instead of beginning with a blank page.
4. **Design in Edit mode.** Select individual elements and style them directly.
5. **Publish and review.** Use Publish to make the app live, then explore the dashboard and continue from there.

## Practical next steps

- Define the first product idea and its essential requirements before starting a build.
- Decide whether Plan mode, a template, or migration of an existing project best fits that idea.
- After the first build, review the published app and dashboard before expanding its scope.
